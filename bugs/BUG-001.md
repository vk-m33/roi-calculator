# BUG-001: Discount Rate input and NPV / IRR outputs are not implemented
Status: RESOLVED
Severity: Critical
Feature: ROI Calculation
File: src/components/CalculatorCore.jsx:9-13,53-70
Reporter: tester

## Description
Three of the five required financial outputs (NPV, IRR) and one of the five required inputs (Discount Rate) are entirely absent. The calculator only computes ROI %, Payback Period, and Net Profit.

## Steps to Reproduce
1. Open the application
2. Inspect the input form — no "Discount Rate" field exists
3. Fill all inputs and view results — no NPV or IRR cards are rendered

## Expected Result
- Input form includes a "Discount Rate" field (percentage, e.g. 10%)
- Results section renders five cards: ROI %, Payback Period, Net Profit, NPV, IRR
- NPV = sum of discounted monthly net cash flows minus initial investment
- IRR = rate that makes NPV = 0 (Newton-Raphson or binary search approximation)

## Actual Result
- `DEFAULT_INPUTS` (CalculatorCore.jsx:9-13) has no `discountRate` key
- `calculate()` (lines 53-70) returns only `{ roi, payback, netProfit }`
- `ResultCards` (lines 17-33) renders only three cards

## Resolution
Added `discountRate: '10'` to `DEFAULT_INPUTS` and a corresponding validation rule (0–100%) in `validate()`. Extended `calculate()` with a NPV loop using the monthly discount rate and a `computeIRR()` binary-search helper that returns the annualised IRR or null when no positive rate exists. Added a "Discount Rate (%)" number input to `InputForm.jsx` and two new result cards (NPV, IRR) in a second row of `ResultCards.jsx`.
