# BUG-005: PDF export omits NPV, IRR outputs and Discount Rate input
Status: OPEN
Severity: Medium
Feature: PDF Export
File: src/utils/exportPDF.js:150-166,175-196,244-270,286-314
Reporter: tester

## Description
The BUG-001 fix added Discount Rate as a required input and NPV / IRR as two new computed outputs. However, `exportPDF.js` was not updated to match. As a result, the exported PDF is inconsistent with the on-screen display: the inputs table omits Discount Rate and the ROI metrics table omits NPV and IRR.

## Steps to Reproduce
1. Enter values in the calculator (Discount Rate at any non-trivial value, e.g. 10%).
2. Note that the results panel shows all five cards: ROI %, Payback, Net Profit, NPV, IRR.
3. Click "Export PDF".
4. Open the downloaded PDF.
5. Observe the INPUTS section — Discount Rate is not listed.
6. Observe the ROI METRICS section — NPV and IRR rows are absent.

The same omission occurs in comparison mode (the three-column metrics table also has no NPV / IRR rows).

## Expected Result
- The INPUTS table in the PDF should include a "Discount Rate" row (e.g. `10.0%`).
- The ROI METRICS table should include NPV and IRR rows beneath Net Profit, matching the five-card layout in `ResultCards.jsx`.
- In comparison mode the metrics table should include NPV and IRR for both scenarios and the Δ column.

## Actual Result
- Single-mode inputs table (`exportPDF.js` lines ~150-166): four rows — Initial Investment, Monthly Revenue, Monthly Costs, Calculation Period — no Discount Rate.
- Single-mode metrics table (`exportPDF.js` lines ~175-196): three rows — ROI, Payback Period, Net Profit — no NPV, no IRR.
- Comparison-mode inputs table (`exportPDF.js` lines ~244-270): same four rows, no Discount Rate.
- Comparison-mode metrics table (`exportPDF.js` lines ~286-314): same three rows, no NPV, no IRR.
