# BUG-003: Comparison Mode — no per-scenario delete button
Status: RESOLVED
Severity: High
Feature: Comparison Mode
File: src/components/CalculatorCore.jsx:150-156
Reporter: tester

## Description
There is no way to remove a single scenario while keeping comparison mode active. The only exit mechanism is a global "Exit comparison" toggle (line 173) that removes both scenarios and returns to single-scenario mode.

## Steps to Reproduce
1. Click "Compare scenarios" to enter comparison mode
2. Look for a way to remove just Scenario B (e.g. a ✕ button in its header) — none exists
3. The only option is to exit comparison mode entirely

## Expected Result
Each scenario should have a remove/close button (×) in its header. Clicking it on Scenario B should remove that scenario's inputs and results from the view while keeping Scenario A active in single-scenario mode (or allowing a new Scenario B to be added again).

## Actual Result
`ScenarioLabel` (lines 72-83) has no delete button. The comparison toggle (line 173) is a binary on/off with no per-scenario control.

## Resolution
Added an `onDelete` prop to `ScenarioLabel` that, when provided, renders a subtle "×" button (gray by default, red on hover). A `deleteScenarioB` handler was added to `CalculatorCore` that sets `comparing` to false, resets `inputsB` to `DEFAULT_INPUTS`, clears `touchedB`, and resets `labelB` to "Scenario B". The prop is passed only to Scenario B's header so Scenario A is unaffected.
