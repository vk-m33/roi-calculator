# BUG-004: PDF Export does not include Monthly Breakdown Table
Status: RESOLVED
Severity: Medium
Feature: PDF Export
File: src/utils/exportPDF.js
Reporter: tester

## Description
The exported PDF includes only a compact ROI metrics summary table. The full Monthly Breakdown Table (month-by-month cumulative P/L and ROI % — up to 36 rows) is not exported. If the spec requires "chart and table" and "table" refers to the monthly breakdown, this is a gap.

## Steps to Reproduce
1. Fill in inputs and view results including Monthly Breakdown
2. Click "Export PDF"
3. Open the downloaded PDF — it contains a bar chart and a small metrics summary table, but not the month-by-month rows

## Expected Result
The exported PDF should include the full monthly breakdown table (columns: Month, Revenue, Costs, Net Profit, Cumulative P/L, ROI %) as a paginated jspdf-autotable section after the metrics summary.

## Actual Result
`exportPDF.js` builds a compact metrics table (lines 175–196) but has no code to iterate over the 12/24/36 monthly rows and add them to the PDF.

## Resolution
Added a monthly breakdown `autoTable` section to `exportPDF.js` for both single and comparison modes. In single mode the table is appended after the break-even info card; in comparison mode separate tables are generated for Scenario A and Scenario B. Each table contains Month, Revenue, Costs, Net, Cumulative P/L, and ROI % columns using the existing `currency` formatter, rendered with the "striped" theme at 8pt font size.
